# TRX Community Rewards H5

Deploy the contents of `dist/` to any static web server. No build step, backend, database, wallet connection, or network submission is used.

## Configuration

Edit `dist/assets/js/config.js` to change the reward asset, reward pool, community name, loading durations, or Safari fallback delay.
